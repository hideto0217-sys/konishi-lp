Amazonの箇条書きを直してもユニットセッション率が動かないのはなぜ？

Bulletを直しても数字が動かないなら、購入者が本当にBulletで迷っているかを先に確認します。

小西マーケティング｜2026.08.27

Amazonを含むECで、enevoltシリーズ累計527万本・iRing国内累計18万個+。両商品の商品ページ構成・販売訴求を設計した小西秀人が、20年のEC実務経験をもとにAmazonの商品ページ改善を解説しています。

まず、Bulletまで読まれているかを確認する

Amazonの箇条書き（Bullet Point）を丁寧に書き直したのに、ユニットセッション率が変わらないことがあります。

それはBulletが不要だからではありません。Amazon公式も、箇条書きは商品の主な特徴を分かりやすく伝える要素として推奨しています。ただし、購入者が止まっている理由がBulletの情報不足とは限らないからです。

Bullet改善が効かないときは、Bulletの書き方より、そもそも何で迷っているかを確認します。

1｜検索結果で選ばれていないなら、Bulletまで読まれていない

表示はあるのにCTRが低い場合、購入者は商品詳細ページへ来る前に離れています。

この状態では、Bulletを改善しても影響は限定的です。メイン画像、タイトル、価格、レビューなど検索結果で見える要素を先に確認します。

2｜価格差で候補から外れているなら、仕様説明を増やしても弱い

競合より価格が大きく高く、その差額に見合う理由が伝わっていない場合、箇条書きを増やすだけでは解決しません。

価格差が妥当なのか、差額を支える商品固有の違いがあるのか、その違いが画像やA+で理解できるかを確認します。

3｜Bulletが画像の読み上げになっている

サブ画像で「軽い」「使いやすい」「耐久性」と伝え、Bulletでも同じことを文章で繰り返すと、情報量は増えても新しい理解は増えません。

Bulletでは寸法、素材、対応範囲、使用条件など、画像だけでは正確に確認しにくい情報を担当させます。

4｜仕様は詳しいが、選ぶ理由につながっていない

素材名、サイズ、機能を詳しく書いても、その仕様がなぜ自分に合うのか分からなければ購入判断は進みません。

仕様 → 何が変わるか → どんな人に合うかまで短くつなげます。ただし、画像で分かる内容は画像へ任せます。

5｜レビュー・配送・在庫など、Bullet外で止まっている

商品ページの説明が十分でも、レビュー評価、配送予定、在庫、Featured Offer、価格などで購入をためらうことがあります。

Amazon Adsも、商品詳細ページの改善ではタイトル、画像、Bulletだけでなく、価格、在庫、レビューなど複数要素を確認するよう案内しています。

6｜改善前後で広告流入が変わっている

Bullet変更と同時期に広告ターゲティングや予算を広げると、ページへ来る人の質が変わります。

ユニットセッション率が動かなくても、Bullet改善が無効だったとは限りません。流入条件を分けて見ます。

Bullet改善が効かないときの確認順

  • CTRが低い → 検索結果の画像・タイトル・価格を確認
  • 価格差が大きい → 差額に見合う理由を確認
  • Bulletが画像と重複 → 役割を分ける
  • 仕様だけで終わる → 使用結果・適合までつなぐ
  • レビュー・配送・在庫 → Bullet外の停止点を確認
  • 広告流入が変化 → 前後条件を分ける

Bulletは重要。でも、BulletだけでCVRは決まらない

Bullet Pointは商品の主な特徴を短く確認するための重要な表示面です。ただし、購入までには画像、価格、レビュー、配送、A+など他の要素も関わります。

書き方を磨く前に、購入者がBulletで迷っているのかを確認する。そこが違えば、先に直す場所も変わります。

よくある質問
AmazonのBulletを改善してもCVRが上がらないのはなぜですか？
購入者が止まっている理由が検索結果、価格、レビュー、配送、広告流入などBullet以外にある場合、箇条書きだけを改善してもCVRは動きにくくなります。
Bulletには何を書くべきですか？
商品の主な特徴に加え、寸法、素材、対応範囲、使用条件など、画像だけでは正確に確認しにくい情報を短く整理します。
画像とBulletは同じ内容でもいいですか？
重要情報を補強する場合はありますが、同じ説明をそのまま重複させるより、画像で分かる内容と文字で確認したい内容を分ける方が効率的です。
